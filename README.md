# 德普游戏 (Texas Hold'em Poker)

一个功能完整的德州扑克游戏，支持机器人和真人玩家对战。

## 游戏特色

- 🎮 完整的德州扑克规则
- 🤖 智能AI机器人
- 👥 支持2-8名玩家
- 🎨 美观的图形界面
- 💰 完整的筹码系统
- 📊 游戏统计功能

## 游戏规则

### 基本流程
1. 每位玩家获得2张底牌
2. 翻牌前下注
3. 发出3张公共牌（翻牌）
4. 发出第4张公共牌（转牌）
5. 发出第5张公共牌（河牌）
6. 摊牌决胜负

### 牌型大小
1. 皇家同花顺
2. 同花顺
3. 四条
4. 葫芦
5. 同花
6. 顺子
7. 三条
8. 两对
9. 一对
10. 高牌

## 安装运行

```bash
pip install -r requirements.txt
python main.py
```

## 功能说明

- **单人模式**：与AI机器人对战
- **多人模式**：邀请朋友一起游戏
- **自定义设置**：调整游戏参数
- **统计记录**：查看游戏历史
